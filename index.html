日柱天干地支

在 iPhone 日曆訂閱五本日曆後，每天會出現全天事件，標題為當日干支，顏色依日干五行。

日柱·木（甲乙） 訂閱 日柱·火（丙丁） 訂閱 日柱·土（戊己） 訂閱 日柱·金（庚辛） 訂閱 日柱·水（壬癸） 訂閱

在 iPhone 上加入

  1. 先把這個網站放到可公開的 HTTPS 網址（例如 GitHub Pages）。本機 file:// 無法讓系統日曆訂閱。
  2. 用 Safari 打開本頁，依序點上面五個「訂閱」。若沒有跳出加入日曆，改走：設定 → 行事曆 → 帳號 → 新增帳號 → 其他 → 加入訂閱的行事曆，貼上各日曆的網址。
  3. 在日曆 App 左上角日曆列表裡確認五本都已開啟。若顏色不對，點「i」自行改成綠 / 紅 / 黃 / 金 / 藍。

涵蓋 2024-01-01 至 2029-12-31。事件為全天、不佔忙碌。日柱依萬年曆（當天 0:00 換日），不是八字 23:00 換日。
