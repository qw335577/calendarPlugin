日柱天干地支

每天兩條：天干、日支各一色。另有一條跨日的月令（節氣換月，例如立春起寅月），顏色跟月支五行。

在 iPhone 上加入

  1. 不要走「新增帳號 / CalDAV」，那會出現「無法驗證帳戶資料」。正確是：設定 → 行事曆 → 帳號 → 新增帳號 → 其他 → 加入訂閱的行事曆。
  2. 伺服器網址貼下面的 https:// 連結。說明、使用者、密碼全部留空，直接下一步。
  3. 木火土金水各加一次。完成後打開日曆 App，確認五本都開啟；顏色不對就點「i」改成綠 / 紅 / 黃 / 金 / 藍。

涵蓋 2024-01-01 至 2029-12-31。月令依節氣（立春寅、驚蟄卯……），不是農曆月份。請把五本日曆手動設成綠 / 紅 / 黃 / 金 / 藍。
